# Project Konversi Suhu

## Deskripsi Project
Project ini merupakan program konversi suhu sederhana yang saya buat menggunakan bahasa pemrograman Go (Golang). Program ini digunakan untuk membantu pengguna mengubah nilai suhu dari satu satuan ke satuan lainnya, seperti Celsius, Fahrenheit, dan Kelvin. Pengguna hanya perlu memasukkan nilai suhu dan memilih jenis konversi yang diinginkan. Setelah itu, program akan menghitung dan menampilkan hasil konversinya secara otomatis.

## Fitur Program
1. Menerima input dari pengguna.
2. Mengolah data berdasarkan instruksi program.
3. Menampilkan hasil pengolahan data ke terminal.
4. Menggunakan struktur percabangan dan perulangan.
5. Memvalidasi input pengguna.

## Teknologi yang Digunakan
1. Bahasa Pemrograman: Go (Golang)
2. Code Editor: Visual Studio Code
3. Version Control: Git
4. Repository: GitHub

## Cara Menjalankan Program
1. Pastikan Go sudah terinstal di komputer.
2. Clone repository GitHub
3. Masuk ke folder project
4. Jalankan program:
   go run main.go
